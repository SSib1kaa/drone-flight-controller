# drone-flight-controller
Flight controller program for UAV/drone systems. Includes attitude control, GPS navigation, and telemetry interface. Optimized for Raspberry Pi and STM32 microcontrollers.

Программа Flight controller для систем беспилотных летательных аппаратов. Включает в себя управление положением, GPS-навигацию и телеметрический интерфейс. Оптимизирована для микроконтроллеров Raspberry Pi и STM32.
